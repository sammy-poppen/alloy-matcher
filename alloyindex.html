Enter a measured chemistry (wt%). Each alloy in the database is checked element by element against its specified range; the alloy that passes every check is the identified grade, followed by the three next-closest grades.

Type an element symbol (e.g. Cr, B, N) and its wt%. Values like <0.01 are accepted. Rows with a blank wt% are skipped. Tick Final element is the remainder (or type rem / bal in a wt% box) to make the last row the balance; its value is computed as 100 − the rest, and it must match the grade’s base metal. An element no grade specifies is shown as “not specified” and doesn’t count against a match.
