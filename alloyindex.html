Alloy Composition Matcher

Enter a measured chemistry (wt%). Each of the alloys in the built-in database — carbon, alloy, stainless and tool steels, aluminum, titanium, nickel, cobalt, copper, magnesium and zinc alloys from US, European, British, French, Japanese, Russian and Chinese standards — is checked element by element against its specified range. The alloy that passes every check is the identified grade, followed by the three next-closest grades.

Measured composition (wt%)

Elementwt%
Type an element symbol (e.g. Cr, B, N) and its wt%. Values like <0.01 are accepted. Rows with a blank wt% are skipped. Tick Final element is the remainder (or type rem / bal in a wt% box) to make the last row the balance; its value is computed as 100 − the rest, and it must match the grade’s base metal. An element a grade doesn’t list is “not specified” and doesn’t count against it — unless it’s above 0.5 wt% (or above the “others each” limit for aluminum and titanium grades), which rules that grade out.
